# You Can't Trade — Design System Direction

## Current visual system

The existing extension uses a dark, calm, chart-first interface with system sans typography, monospace values, blue accent, semantic result colors, native controls, and responsive review surfaces. Preserve keyboard focus, text labels, reduced motion, and evidence before decoration.

## Target principles

- Make the next useful investigation obvious.
- Put chart/evidence before dense tables.
- Use color with text, never as the only result signal.
- Keep capture to one primary action.
- Show confidence, sample size, and unknowns alongside findings.
- Keep deterministic facts visually distinct from authored notes and AI interpretation.

## Target navigation

Home, Trades, Explore, Review, Memory, Experiments, Import, Settings. This is a future IA, not a claim that the current UI already has every section.

## Accessibility and performance

Use semantic landmarks, labeled controls, visible focus, keyboard dialogs, reduced-motion support, lazy screenshot loading, bounded list rendering, and no AI call merely because a page opened.
