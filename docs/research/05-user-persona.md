# User Persona

## Primary User

The first version of VantageForge is built for one specific type of trader.

We intentionally optimize for a narrow audience instead of trying to serve everyone.

---

# Profile

Experience

- 1–5 years of trading experience

Trading Style

- Discretionary
- ICT / SMC
- Price Action
- Liquidity Based
- Market Structure Based

Markets

- Forex
- Crypto
- Futures

Primary Charting Platform

- TradingView

---

# Current Workflow

A typical trading session looks like this.

Research

↓

Analyze Market Structure

↓

Mark Liquidity

↓

Find Setup

↓

Execute Trade

↓

Take Screenshot

↓

Think about Journaling

↓

Never Actually Journal

- TradingView

- Notion (sometimes)

- Mobile Notes

# Daily Frustrations

"I know I should journal."

"I'll do it later."

"I forgot why I entered."

"I don't remember how I felt."

"I know I've made this mistake before."

"I have hundreds of screenshots but never review them."

"I spend more time organizing than learning."

---

# Goals

The trader wants to:

- Become consistently profitable.
- Follow their trading plan.
- Eliminate repeated mistakes.
- Build confidence.
- Improve discipline.
- Spend less time on manual documentation.

---

# Behaviors

The trader is visual.

Screenshots are often more valuable than spreadsheets.

The trader remembers charts better than numbers.

The trader thinks in market structure rather than statistics.

---

# What Success Looks Like

At the end of a trading session, the trader should only need to perform one simple action.

Everything else should happen automatically.

Instead of spending time documenting the trade, the trader spends time reviewing and learning.

---

# Product Principles Derived From This Persona

Every feature should answer one of these questions.

Does it reduce manual work?

Does it reduce friction?

Does it improve learning?

Does it help the trader review faster?

If the answer is no, the feature should not be built.

---

# Design Implications

The interface should feel calm.

The number of clicks should be minimal.

Typing should be optional whenever possible.

Charts should always come before tables.

Review should always come before analytics.

Learning should always come before reporting.

---

# Success Metric

If a trader consistently uses VantageForge after every trading session for six months without feeling that journaling is a burden, the product has succeeded.
